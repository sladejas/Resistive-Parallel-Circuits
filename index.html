Parallel Circuit Laws & Reference Sheet

1. Voltage Across Parallel Branches

In a parallel circuit, every branch component is connected directly across the voltage source terminals.

$V_S = V_1 = V_2 = V_3 = \dots = V_n$

2. Kirchhoff's Current Law (KCL)

The sum of all individual branch currents entering a junction equals the total current supplied by the source.

$I_T = I_1 + I_2 + I_3 + \dots + I_n$

3. Total Resistance ($R_{eq}$) Formulas

General Reciprocal Formula (2 or 3+ branches):

$\frac{1}{R_{eq}} = \frac{1}{R_1} + \frac{1}{R_2} + \frac{1}{R_3}$

Product-Over-Sum Shortcut (2 Resistors ONLY):

$R_{eq} = \frac{R_1 \times R_2}{R_1 + R_2}$

4. Branch Currents & Circuit Power

Calculate current for each individual branch using Ohm's Law:

$I_n = \frac{V_S}{R_n}$

Total circuit power dissipation:

$P_T = V_S \times I_T = P_1 + P_2 + P_3$
